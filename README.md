# Message Actions Manager

A SillyTavern extension to customize the order and visibility of message action icons.

## Features

<img width="506" height="689" alt="image" src="https://github.com/user-attachments/assets/4d831202-7a0d-427b-be9f-9639cf6ac059" />


* **Two groups**: Icons can be divided into two groups. **Always Display** icons are always visible in the message header, regardless of whether *Expand Message Actions* is enabled. **More** icons are hidden until the `…` button is clicked.
* **Drag & drop** to reorder icons or move them between groups, with a live preview.
* **Show/hide** any icon with a checkbox.
* **Auto-detects** icons from other extensions; new ones are added to the end of Always Display.
* **Touch-friendly** drag handles for mobile.

## Usage

Open **Extensions → Message Actions Manager**.

| Button | Action |
| --- | --- |
| Show All / Hide All | Toggle every icon at once |
| Clean Up | Remove entries no longer detected (e.g. uninstalled extensions) |
| Reset | Restore defaults |

# Message Actions Manager

메시지 액션 아이콘의 순서와 표시 여부를 원하는 대로 정리하는 SillyTavern 확장입니다.

## 주요 기능

<img width="506" height="689" alt="image" src="https://github.com/user-attachments/assets/4d831202-7a0d-427b-be9f-9639cf6ac059" />

* **두 개의 그룹**: 아이콘을 두 그룹으로 나눌 수 있습니다. **Always Display**는 *Expand Message Actions* 활성화 여부와 관계없이 메시지 헤더에 항상 표시되며, **More**는 `…` 버튼을 눌렀을 때만 펼쳐집니다.
* **드래그 앤 드롭**으로 순서 변경 및 그룹 간 이동이 가능하며 실시간 미리보기를 제공합니다.
* 체크박스로 아이콘 **표시/숨김**을 설정할 수 있습니다.
* 다른 확장의 아이콘을 **자동 감지**하며, 새 아이콘은 Always Display 맨 뒤에 추가됩니다.
* 모바일에서도 쉽게 이용할 수 있는 터치 친화적 드래그 핸들을 지원합니다.

## 사용법

**Extensions → Message Actions Manager** 메뉴를 실행하세요.

| 버튼 | 동작 |
| --- | --- |
| Show All / Hide All | 모든 아이콘 한 번에 표시/숨김 |
| Clean Up | 현재 감지되지 않는 항목 제거 (삭제된 확장 등) |
| Reset | 초기화 |
