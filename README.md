# Message Actions Manager

A SillyTavern extension to customize the visibility and order of message action icons.

Icons can be split into two groups: **Always**, which is always shown in the message header regardless of the *Expand Message Actions* user setting, and **More**, which is only shown after clicking the `…` button. Everything is managed from the extension panel. Icons added by other extensions are detected automatically and appended to the end of the Always group.

<br> 

## Main Features

### 0. Preview
Shows how the icons will look in an actual message. The left side is the Always group, and the right side is the More group that unfolds when you click `…`. You can drag icons here to reorder them too.

### 1. Always Group
Always visible in the message, regardless of *Expand Message Actions*. Use the handle on the left of each row to reorder.

### 2. More Group
Always tucked away behind the `…` button, regardless of *Expand Message Actions*. Shown only after you click it. Use the handle on the left of each row to reorder, or drag icons between the two groups.

### 3. Visibility
Uncheck **Show** to hide an icon from the message actions.


<br> 

## Extras

### 4. Remove shadows from message action icons
Removes shadows from the icons.

### 5. Scroll icons sideways instead of wrapping to a new line
When there are too many icons, keeps them on one line and lets you scroll horizontally instead of wrapping.

### 6. Clean Up
Removes leftover entries from extensions that have been uninstalled or disabled.
